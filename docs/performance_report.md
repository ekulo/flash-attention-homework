## 3. 关键结论(实测)

1. **朴素 → 阶段2**:~7.6x(N=256)到 ~43x(N=2048);**阶段2 → 阶段3
   (Tensor Core)**:6.1x / 6.7x / 7.0x / 7.2x(N=256/512/1024/2048),满足
   "阶段间 ≥2~3x" 要求;阶段3 → 阶段4(cp.async)再 +3%(N≥1024)。
2. 误差全部达标:FP32 vs PyTorch 最大 ~1e-6 级,FP16 最大 8e-5 级
   (<1e-3);阶段6 与 eager 逐位一致(maxdiff=0)。
3. 阶段5 为单卡**虚拟 2 rank**(同流串行执行两个 rank,含 host 编排与
   peer 复制):N=256 d=128 时甚至显示 1.32x"加速"(单 rank 基线同样被
   编排开销支配),总体 0.58~1.32x,无稳定加速符合预期;真实多卡需 ≥2
   GPU 实测(kernel 按 rank 并行、每卡一半 key 块)。
4. CUDA Graph 消除逐次 launch 开销:8/8 配置省 7~39% 延迟(d=128 N=256
   例外 -3.6%,tiny 规模噪声),N=256 d=64 最显著(46.4→28.2 us)。
5. 曲线形态符合预期:朴素 O(N²) 时间陡升;阶段2+ 平滑;吞吐随 N 上升,
   说明小规模未喂饱 36 SM。
